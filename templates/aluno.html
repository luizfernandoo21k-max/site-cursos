Aula 1 — Introdução ao HTML

Nesta aula você vai conhecer o HTML e entender como uma página de internet é estruturada.

O que é HTML?

HTML é a linguagem usada para estruturar páginas da internet. Com HTML podemos criar títulos, textos, imagens, links e botões.

🧱 Estrutura básica

Uma página HTML possui uma estrutura organizada. Os elementos principais são HTML, HEAD e BODY.

💻 Exemplo

<h1>Meu primeiro site</h1>
<p>Olá! Este é meu primeiro site.</p>
<button>Clique aqui</button>

📝 Exercício

Crie mentalmente um título para o site que você gostaria de fazer.

🎯 Objetivo: entender para que serve o HTML.

Aprenda a criar a estrutura básica de uma página HTML e organizar seus principais elementos.

🌐 Criando sua primeira página

Agora que você já conhece o HTML, vamos aprender a montar uma página simples do zero.

💻 Primeiro código

<!DOCTYPE html>
<html>
<head>
    <title>Meu site</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
    <p>Minha primeira página.</p>
</body>
</html>

📝 Exercício

Pense em um título e uma frase para sua própria página.

🎯 Objetivo: aprender a montar a estrutura básica de uma página HTML.

🎨 O que é CSS?

CSS é a linguagem usada para deixar uma página HTML mais bonita e organizada.

✨ O que podemos mudar com CSS?

  • 🎨 Cores
  • 🔤 Tamanho e estilo das letras
  • 📦 Espaçamento
  • 🔘 Aparência dos botões
  • 📱 Organização da página

💻 Exemplo

h1 {
    font-size: 30px;
}

p {
    font-size: 18px;
}

📝 Exercício

Imagine uma cor para o título do seu primeiro site.

🎯 Objetivo: entender como o CSS modifica a aparência de uma página.

🔘 O que são botões?

Botões permitem que o visitante interaja com uma página. Eles podem levar para outra página ou executar uma ação.

💻 Criando um botão

<button>Clique aqui</button>

🎨 Personalizando com CSS

button {
    padding: 12px;
    font-size: 18px;
}

📝 Exercício

Crie uma ideia de botão para o seu site. Por exemplo: "Conheça o curso".

🎯 Objetivo: aprender a criar e personalizar botões.
